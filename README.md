# CodeInAction

A collection of projects built with Claude Code.

## Projects

### [UIGen](./uigen)

AI-powered React component generator with live preview. Describe a component in plain language and watch Claude generate it in real time, with an in-browser preview and code editor.

**Stack:** Next.js 15, React 19, TypeScript, Tailwind CSS v4, Prisma/SQLite, Anthropic Claude

See [uigen/README.md](./uigen/README.md) for setup and usage instructions.

## CI/CD

This repo uses GitHub Actions for continuous integration and the [Claude Code Action](https://github.com/anthropics/claude-code-action) for AI-assisted code review on pull requests.
